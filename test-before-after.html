Componente Before-After Reutilizável

Demonstração do novo sistema de before-after com data attributes.

🚀 Como usar

<div class="before-after" data-before="image1.png" data-after="image2.png"></div>

Pronto! O JavaScript inicializa automaticamente e os textos TQS25/TQS26 são fixos.

✨ Recursos

  • ✅ Ultra simples: apenas 1 div com data attributes
  • ✅ Auto-inicialização: funciona automaticamente
  • ✅ Elementos dinâmicos: suporta adição via JavaScript
  • ✅ Mobile-first: funciona perfeitamente em touch
  • ✅ Textos fixos: TQS25 e TQS26 sempre presentes
  • ✅ Visual consistente: segue o design system do site
  • ✅ Performance otimizada: CSS moderno com clip-path
